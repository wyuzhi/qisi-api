连接你的创作工具。

在工作台管理余额和 API Key，通过异步任务接口生成图片与视频。你的 qisiTV 项目仍可保存在本机。

当前为部署准备版本。在线支付需开通商户渠道；模型需由管理员核对成本并配置售价后启用。创建任务会消耗余额，请先查看价格。

1. 获取自己的 Key

登录后进入「API 令牌」，创建专用 Key。每个应用使用独立 Key，并设置模型限制、有效期和额度。不要把 Key 放入公开代码或共享页面。

2. 创建任务

基础地址为本站栏目地址。使用 Authorization: Bearer 你的Key，不使用上游服务商的 Key。

3. 查询结果
返回 data.task_id 后，使用同一个用户的 Key 查询。状态为 queued、running、completed 或 failed。完成后从 data.result.images 或 data.result.videos 获取结果并及时下载。网络超时不等于任务未提交，不要自动重发生成请求。
支持的参数
首版适配 Seedream 4.5（doubao_seedream_4_5）与 Seedance 2.5（doubao_seedance_2_5），是否可用以价格页和管理员配置为准。
  • 图片：prompt、resolution（1080p / 1440p / 2160p）、aspect_ratio、image_urls。
  • 视频：prompt、duration（4–30 整数秒）、resolution（480p / 720p）、aspect_ratio、image_urls，或 first_image_url / last_image_url。
  • 视频音频开关：kwargs.generate_audio，布尔值。
  • 参考图使用 HTTPS 地址。首版不提供自动时长、输入视频或输入音频。
这里是 LikeAI 风格任务接口，不是 OpenAI 聊天接口。Agent 或应用需按照本页接口接入。
后台手动充值
管理员进入「用户管理」，点击用户的「编辑」，再选择「手动充值 / 调整额度」。选择增加、扣减或设置余额，输入金额，检查调整前后的预览再确认。操作人、时间、对象及余额变化会记录在操作日志中，用户可在账单日志查看充值类型记录。
手动加余额不表示平台收到线上款项。线下收款与赠送额度应由管理员自行核对后录入；不要连续重复提交同一笔调整。
数据和费用
中转服务保存账户、余额、令牌摘要、任务及账单记录。生成时提示词和参考素材会经过中转服务及 LikeAI；结果链接可能随任务记录保存。它不是本地项目备份服务，请把成品下载到项目文件夹。
