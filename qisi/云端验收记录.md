## 实测结果

在正式域名运行 `.local-tests/verify-cloud.mjs`，20 项检查通过，无付费生成调用：

- 初始化状态、管理员账号和管理设置在独立云端进程中保留。
- 注册开启，服务端要求至少 15 字符密码；短密码注册失败。
- 实际创建普通测试账号，客户端注入管理员角色和余额无效；新用户余额为 0，没有默认 API 令牌。
- 新用户、邀请人及被邀请人赠额均为 0；`RetryTimes=0`。
- 管理员可以读取管理设置，普通用户不能；退出后旧会话请求被拒绝。
- Cookie 带 Secure、HttpOnly，作用域为 `/api-service`。
- 渠道数为 0，五种未配置的在线充值开关均为关闭。

另行验证：已认证的 `/api/user/self` 返回 `Cache-Control: no-store, no-cache, must-revalidate, private, max-age=0`，Vercel 为 MISS；页面及状态接口返回 200，未登录请求 `/api/option/` 和 `/api/token/` 返回 JSON 401。三类代理规则都保留 `/api-service` 前缀及必要的末尾斜杠。

浏览器已在正式域名登录管理员并显示真实后台。qisiTV 模型配置空 Key 的错误以内联文字显示；16 项相关前端测试、类型检查和浏览器版构建通过。此次未创建付费任务，也未测试真实收款。

管理员密码、数据库密码、会话密钥和测试账号凭据仅保存在本机忽略目录及相应服务的私密配置中，不包含在本记录或公开源码中。
